# HealthAI knowledge base

Short self-care and escalation notes used for retrieval (RAG). Each note is
written in plain language for this project from general public-health
guidance and links to a MedlinePlus page for further reading. They are not
clinical guidelines and have not been reviewed by a clinician.

Format: front matter (`id`, `title`, `url`, `symptoms`) then `##` sections.
Each section is embedded and retrieved on its own, and cited by
`<id>#<section-slug>`.
