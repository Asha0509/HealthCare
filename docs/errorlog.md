# Error log

Real things that broke in this project and how they were fixed, mined from the git history, the README's "what did not work" section, and the fixes made during the latest hardening pass. Nothing here is invented: each row names the commit that holds the fix, and the evidence notes under the table say which parts come from git and which are stated by the maintainer without a trace in git.

Related: [architecture.md](architecture.md), [HLD.md](HLD.md), [LLD.md](LLD.md), [results.md](results.md).

Dates are commit dates (author date, as recorded; the history mixes time zones). Commit hashes are short ids; look them up with `git show <hash>`.

## Known and not fixed

Honest list of issues found while writing the docs. None is hidden; none is fixed in this change.

| Issue | Where | Impact |
|---|---|---|
| Rules-only pipeline misses indirect emergency wording and under-triages Urgent cases | `evals/results/rules.json`: 2 critical misses (`e18`, `e20`), `e19` told Urgent, 12 of 20 Urgent cases told HomeCare | The agent is meant to close this gap but has no measured result; see [results.md](results.md) |
| The agent pipeline and the optional decision model have never been evaluated in this repository | No `agent.json` or `decision.json` in `evals/results/` | No accuracy or coverage claim can be made |
| `.vercelignore` ends with a corrupted pattern, `models/models/*.joblib` followed by a run of `z` characters | Introduced in `9cd03ca` | The `.joblib` ignore rule does not match; harmless today because no such files are committed |
| Stale docstrings: `llm_client.py` names Llama models; `nlp_engine.py` and `adaptive_engine.py` mention Gemini; `models/disease_classifier.py` says XGBoost and different dataset counts than the code and metadata | Code comments | Misleads a reader; behaviour is correct |
| Evals page and tour describe expected levels as "a careful clinician" choice, while the labels are author-written | `frontend/src/pages/Evals.jsx`, `components/Tour.jsx` | Overstates label provenance; the README, Landing page and report note say otherwise |
